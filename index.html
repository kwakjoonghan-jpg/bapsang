우리집 밥상

처음 한 번만 연결하면 돼요. 아내분은 나중에 보내드리는 초대 링크만 열면 되니 이 과정을 하지 않아도 돼요.

  1. Firebase 콘솔에서 프로젝트 만들기 (이름은 자유, 애널리틱스는 꺼도 돼요)
  2. 왼쪽 메뉴 빌드 › Firestore Database › 데이터베이스 만들기
    위치는 asia-northeast3 (서울), 프로덕션 모드로 시작
  3. Firestore의 규칙 탭에 아래 내용을 통째로 붙여넣고 게시 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /families/{fam}/{document=**} {
      allow read, write: if fam.size() >= 20;
    }
  }
}
  4. 톱니바퀴 프로젝트 설정 › 일반 › 내 앱에서 웹 아이콘 </>으로 앱 등록 → 나오는 firebaseConfig 부분을 복사해서 아래에 붙여넣기

누가 쓰는 폰인가요?

요청이나 장보기 목록을 누가 보냈는지 구분하는 데 써요. 나중에 설정에서 바꿀 수 있어요.
